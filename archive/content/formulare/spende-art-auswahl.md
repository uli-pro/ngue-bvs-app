# Spende-Art-Auswahl - Formular-Texte

## Überschrift:
**"Für wen möchten Sie diesen Vers sponsern?"**

## Radio-Button Optionen:

### Option 1 (Standard):
○ **Als Einzelperson (für mich selbst)**
*Sie erhalten das Zertifikat und die Spendenbescheinigung*

### Option 2:
○ **Als Gruppe (Familie, Jugendgruppe, Verein, etc.)**
*Das Zertifikat wird auf Ihre Gruppe ausgestellt und an Sie als Kontaktperson gesendet*

### Option 3:
○ **Als Geschenk für jemand anderen**
*Der Empfänger erhält ein Geschenk-Zertifikat, Sie die Spendenbescheinigung*

## Dynamische Inhalte:

### Bei Auswahl "Als Gruppe":
Zusätzliche Felder werden eingeblendet (siehe gruppenspende-daten.md)

### Bei Auswahl "Als Geschenk":
Zusätzliche Felder werden eingeblendet (siehe geschenk-empfaenger-daten.md)

## Technische Hinweise:
- JavaScript für dynamisches Ein-/Ausblenden
- Validierung: Eine Option muss gewählt sein
- Standard-Auswahl: "Als Einzelperson (für mich selbst)"
