# System-Meldungen

## Lade-Zustände

### Allgemein
- **Laden:** "Wird geladen..."
- **Suche läuft:** "Verse werden gesucht..."
- **Verarbeitung:** "Ihre Anfrage wird verarbeitet..."
- **Fast fertig:** "Noch einen Moment..."

### Spezifisch
- **Verse laden:** "Verfügbare Verse werden geladen..."
- **Zahlung:** "Zahlung wird verarbeitet..."
- **PDF erstellen:** "Ihr Zertifikat wird erstellt..."
- **E-Mail senden:** "E-Mail wird versendet..."

## Wartungs-Meldungen

### Geplante Wartung
- **Ankündigung:** "Geplante Wartungsarbeiten am {DATUM} von {ZEIT_START} bis {ZEIT_ENDE}."
- **Kurz vor Wartung:** "Die Website wird in {MINUTEN} Minuten für Wartungsarbeiten offline gehen."
- **Während Wartung:** "Wir führen gerade Wartungsarbeiten durch. Bitte versuchen Sie es in {MINUTEN} Minuten erneut."

### Ungeplante Unterbrechung
- **Störung:** "Es liegt momentan eine technische Störung vor. Wir arbeiten an einer Lösung."
- **Teilausfall:** "Einige Funktionen sind momentan nicht verfügbar."

## Browser-Kompatibilität

### Veralteter Browser
- **Update empfohlen:** "Ihr Browser ist veraltet. Für die beste Erfahrung empfehlen wir ein Update."
- **Funktion nicht unterstützt:** "Diese Funktion wird von Ihrem Browser nicht unterstützt."
- **Alternative Browser:** "Bitte verwenden Sie Chrome, Firefox, Safari oder Edge."

### JavaScript deaktiviert
- **JS erforderlich:** "Diese Website benötigt JavaScript. Bitte aktivieren Sie JavaScript in Ihren Browser-Einstellungen."

## Sicherheits-Meldungen

### Session
- **Bald abgelaufen:** "Ihre Sitzung läuft in {MINUTEN} Minuten ab. Möchten Sie angemeldet bleiben?"
- **Abgelaufen:** "Ihre Sitzung ist aus Sicherheitsgründen abgelaufen. Bitte melden Sie sich erneut an."
- **Andere Anmeldung:** "Sie wurden von einem anderen Gerät angemeldet. Bitte melden Sie sich erneut an."

### Sicherheits-Checks
- **Captcha erforderlich:** "Bitte bestätigen Sie, dass Sie kein Roboter sind."
- **Verdächtige Aktivität:** "Aus Sicherheitsgründen wurde Ihre Anfrage blockiert. Bitte kontaktieren Sie den Support."

## Offline-Meldungen

### Keine Internetverbindung
- **Offline:** "Sie sind offline. Bitte prüfen Sie Ihre Internetverbindung."
- **Verbindung verloren:** "Die Verbindung zum Server wurde unterbrochen."
- **Wieder online:** "Sie sind wieder online!"

## Datenbank-Status

### Synchronisation
- **Aktualisierung:** "Daten werden aktualisiert..."
- **Synchronisiert:** "Alle Daten sind auf dem neuesten Stand."
- **Konflikt:** "Es gab einen Konflikt. Ihre Änderungen werden überprüft."

## Limits und Beschränkungen

### Rate Limiting
- **Zu viele Anfragen:** "Sie haben zu viele Anfragen gesendet. Bitte warten Sie {SEKUNDEN} Sekunden."
- **Tägliches Limit:** "Sie haben das tägliche Limit erreicht. Versuchen Sie es morgen erneut."

### Datei-Limits
- **Zu groß:** "Die Datei ist zu groß. Maximale Größe: {MAX_SIZE}."
- **Falsches Format:** "Dieses Dateiformat wird nicht unterstützt."

## Info-Meldungen

### Hinweise
- **Tipp:** "Tipp: {HINWEIS_TEXT}"
- **Neu:** "Neu: {FEATURE_BESCHREIBUNG}"
- **Info:** "Gut zu wissen: {INFO_TEXT}"

### Erste Schritte
- **Willkommen:** "Willkommen! Hier können Sie Ihren ersten Vers auswählen."
- **Tutorial:** "Möchten Sie eine kurze Einführung?"
- **Hilfe verfügbar:** "Benötigen Sie Hilfe? Klicken Sie auf das Fragezeichen."

## Debug-Meldungen (nur Entwicklung)

### Fehler-Details
- **Fehlercode:** "Fehler {CODE}: {BESCHREIBUNG}"
- **Stack-Trace:** "Technische Details wurden in die Konsole geschrieben."
- **Support-ID:** "Bitte nennen Sie diese ID dem Support: {TICKET_ID}"
