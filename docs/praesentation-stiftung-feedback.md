# NGÜ Bibelvers-Sponsoring App - Präsentation für Peter-Schöffer-Stiftung

## Zusammenfassung für Feedback-Runde

### 1. Projekt-Überblick in 30 Sekunden

**Was:** Web-App für individuelles Bibelvers-Sponsoring der NGÜ-Übersetzung  
**Ziel:** 11.000 AT-Verse á 100€ finanzieren  
**Wie:** Spender wählen Vers → Zahlen online → Erhalten Zertifikat + Spendenbescheinigung  
**Wann:** Launch geplant für [Datum einfügen]  
**Technik:** Moderne Web-App mit Suchfunktion, automatischer Abwicklung, Stripe-Zahlung

---

## 2. Kernfunktionen der App

### 🎯 **Vers-Auswahl (3 Wege)**
1. **Top 3 positive Verse** (Default-Anzeige)
2. **Suche nach Bibelstelle** (Dropdown: Buch/Kapitel/Vers)
3. **Thematische Suche** (z.B. "Hoffnung", "Kraft", "Trost")

### 💳 **Spende-Optionen**

- **Als Einzelperson** (Standard)
- **Als Gruppe** (Familie, Jugendgruppe, Verein)
- **Als Geschenk** (für andere Person)

### 📄 **Automatische Dokumente**
- Personalisiertes Zertifikat (sofort per E-Mail)
- Spendenbescheinigung (bei Einzelpersonen automatisch)
- Bei Gruppen: Hinweis auf manuelle Anfrage

### 🔍 **Besonderheit: Intelligente Alternative**
Wenn gewünschter Vers bereits vergeben → System schlägt ähnliche Verse vor

## 5. User Journey - Vereinfacht

```
Start → Vers wählen → Spende-Art → Daten eingeben → Zahlen → Zertifikat erhalten
         ↓               ↓              ↓
    (3 Optionen)   (Einzel/Gruppe/   (E-Mail +        
                    Geschenk)      opt. Adresse)
```

**Besonderheit:** Vers wird während Checkout 15 Min. reserviert
