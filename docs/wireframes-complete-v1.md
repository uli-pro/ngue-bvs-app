## Technische Anmerkungen zu den Wireframes:

### Responsive Design
- Alle Wireframes sind für Desktop konzipiert
- Mobile Versionen: Navigation wird zu Hamburger-Menü
- Vers-Karten stapeln sich vertikal auf mobilen Geräten
- Formulare werden einspaltiger

### Interaktive Elemente
- **Vers-Reservierung**: 15-Minuten-Timer bei Vers-Auswahl
- **AJAX-Suche**: Live-Suche bei Keyword-Eingabe
- **Progressive Disclosure**: Zusatzfelder erscheinen bei Bedarf
- **Loading States**: Während Stripe-Weiterleitung

{

## 21. State Management & User Flow Logic

### Checkout-Prozess States

```
STATES:
- verse_selected
- personal_data_entered  
- payment_confirmed
- payment_processing
- payment_successful
- payment_failed

TRANSITIONS:
verse_selected → personal_data_entered (via form submission)
personal_data_entered → payment_confirmed (via summary page)
payment_confirmed → payment_processing (via Stripe redirect)
payment_processing → payment_successful/failed (via Stripe webhook)
```

### Session Storage (Browser)
```javascript
// Beispiel Session State
{
  selected_verse: {

  },

    wants_receipt: true,
    // ... weitere Felder
  },
  checkout_step: "personal_data_entered"
}
```

## 23. Accessibility & WCAG Compliance

### Keyboard Navigation
- Alle interaktiven Elemente mit Tab erreichbar
- Skip-Links am Seitenanfang
- Focus-Indikatoren sichtbar
- Logische Tab-Reihenfolge

### Screen Reader Support
- Semantic HTML5 (header, main, aside, footer)
- ARIA-Labels für komplexe Widgets
- Alt-Texte für alle Bilder
- Beschreibende Link-Texte
